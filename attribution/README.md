# attribution

| Script | Does |
|---|---|
| `components.py` (launcher `attribution.sh`) | SVD components of ΔW, selection/evaluation split, integrated-gradient attribution, selections |
| `attribution_report.py` | Tables of the cross-behavior attribution map |
| `selection_sets.py` | Probe selections, the CORE set and the magnitude and random baselines |
| `random_set_report.py` | Selected sets against their matched random distributions |
| `param_decomp.py` | Behavior-specific decomposition of the update (Qwen2.5-7B) |

Commands: Sections 4.3 and 4.4 of the [pipeline guide](../docs/pipeline.md).
