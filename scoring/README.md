# scoring

| Script | Does |
|---|---|
| `pairs.sh` | Builds the medical pair sets (`data_construction/behavior_pairs.py`) and scores every pair set under base, C and E |
| `score_pairs.py` | Teacher-forced log-probability scores of every pair set |
| `pair_shift_report.py` | Raw E − C shifts and residual shifts |

Commands: Sections 3.4 and 4.2 of the [pipeline guide](../docs/pipeline.md).
